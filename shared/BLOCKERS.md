# Blockers

> 진행을 막는 이슈. 해결되면 "Resolved" 섹션으로 이동.

## Format
```
### BL-NNN: <제목>
**Reported by:** <agent>
**Date:** YYYY-MM-DD
**Severity:** P0 (즉시 해결) | P1 (이번 phase 내) | P2 (다음 phase)
**Description:** 무엇이 막혔는지
**Needs:** 누구의 결정/액션이 필요한가
**Proposed Resolutions:** 가능한 해결책 2-3개
```
